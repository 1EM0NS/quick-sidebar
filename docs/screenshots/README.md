## 截图建议

- **用 `Win + Shift + S`** 截区域：框选浏览器窗口即可，截出来的图干净
- 想带浏览器窗口边框（看起来更真实），可以直接 `Alt + PrtSc` 截整个活动窗口
- 页面内容建议是**有正文的普通网页**（比如一篇技术文章），这样能看出侧边栏"不挡内容"的效果；纯白页面会看不出差别
- 收藏条数建议放 **6～10 条**，太少了展示不出图标条，太多了面板显示不全

## 为什么要重新截

之前尝试用脚本自动截（离屏浏览器 + 加载扩展），功能都跑通了，但有两个问题没法解决：

1. **右键菜单是浏览器原生 UI**，自动化截图抓不到
2. 部分网站的 favicon 在自动化环境里加载不出来，会显示成占位图标

真实使用场景下自己截，效果和真实度都会更好。
