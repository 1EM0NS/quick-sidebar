## 截图小建议

- 用 `Win + Shift + S` 框选浏览器窗口，截出来的图干净
- 想带浏览器边框的话直接 `Alt + PrtSc` 截活动窗口
- 页面最好是个有正文的普通网页（比如一篇技术文章），这样能看出来侧边栏不挡内容，纯白页面看不出效果
- 收藏放 6～10 条，太少了图标条看不出来，太多了面板显示不全
