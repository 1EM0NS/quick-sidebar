# 快捷侧边栏

> 一个会自动收起的浏览器侧边栏：右键收藏网页，鼠标靠近才滑出来，移开就消失。

适用于 Microsoft Edge（Chromium 内核）的 Manifest V3 扩展。已上架 Edge 加载项商店。

## 它解决什么问题

大多数侧边栏的通病是**永远占着地方**——你不需要它的时候，它也在那儿，把正文挤窄。

这个侧边栏的默认状态是**几乎没有**：屏幕右侧只留一个约 22 像素宽的半透明把手（你可能根本注意不到它）。要用了，鼠标靠近，它才滑出来；鼠标移开 0.6 秒，它自己收回去。

它不做第二个书签管理器，只做一件事：**把当前正在看的页面，一键放进随手能够到的地方。**

## 三种状态

| 状态 | 宽度 | 什么时候出现 |
| --- | :---: | --- |
| **把手**（handle） | 22px | 默认。贴在屏幕右缘，半透明，基本不挡内容 |
| **图标条**（strip） | 48px | 鼠标悬停把手时滑出，只显示网站图标，一列排开 |
| **详情面板**（expanded） | 300px | 点图标条顶部的展开按钮，显示标题、网址，可搜索 / 编辑 / 删除 / 拖拽排序 |

| 收起态 | 图标条 | 详情面板 |
| :---: | :---: | :---: |
| ![收起态](docs/screenshots/01-handle.png) | ![图标条](docs/screenshots/02-strip.png) | ![详情面板](docs/screenshots/03-expanded.png) |

## 功能

- **右键收藏** — 在任意网页上右键 →「添加到侧边栏」，标题和图标自动抓取。重复添加同一个网址只会更新，不会出现两条。
- **自动收起** — 鼠标移开 0.6 秒后收回把手。但正在搜索 / 编辑时**不收**，拖拽排序时**也不收**——这几个时刻打断的成本最高。
- **一点就走** — 点图标或卡片，在新标签页打开；只允许 `http` / `https`，编辑时输入 `javascript:` 之类会被拦下。
- **搜索过滤** — 在面板顶部按标题或网址实时过滤。
- **行内编辑** — 直接改标题和网址，回车保存、Esc 取消。
- **拖拽排序** — 长按卡片拖到别的位置，顺序即存。
- **导出 / 导入** — 面板底栏一键导出 JSON 备份，换机时可导入；导入按网址去重合并，不会产生重复项。
- **工具栏开关** — 点扩展图标可以在「完全显示 / 完全隐藏」之间切换，状态按设备保存。
- **样式隔离** — 整个界面跑在 Shadow DOM 里，不会被宿主的 `*` 选择器、`box-sizing` 或行高污染，也不会反过来污染网页。

## 安装

### 从商店安装

在 Microsoft Edge 加载项商店搜索「快捷侧边栏」安装即可。

### 开发者模式加载（本地）

1. 下载或克隆本仓库
2. 打开 `edge://extensions/`
3. 打开左下角「开发人员模式」
4. 点「加载解压缩的扩展」，选择本仓库根目录（含 `manifest.json` 的那层）

> 仓库里的 `manifest.json` 保留了商店用的 `key` 字段，所以本地加载出来的扩展 ID 与商店版一致，**扩展数据可以互通**。

## 使用

| 想做什么 | 怎么做 |
| --- | --- |
| 收藏当前网页 | 页面任意位置右键 →「添加到侧边栏」 |
| 打开图标条 | 鼠标移到屏幕右缘的把手 |
| 展开详情面板 | 点图标条顶部的 `⟨` |
| 搜索 | 面板顶部输入框，按标题或网址过滤 |
| 编辑某条 | 鼠标悬停卡片 → 点 `✎` |
| 删除某条 | 鼠标悬停卡片 → 点 `✕` |
| 调顺序 | 按住卡片拖到目标位置 |
| 备份 / 恢复 | 面板底栏 `⇩` 导出、`⇧` 导入 |
| 完全隐藏侧边栏 | 点浏览器工具栏上的扩展图标 |
| 强制收起 | 把鼠标移开，0.6 秒后自动收回 |

## 数据与同步

数据只有一份，但存了两处，规则如下：

1. **写**：优先写 `chrome.storage.sync`，同时镜像一份到 `storage.local`
2. **读**：先读 `sync`，为空再读 `local`
3. **超限**：`sync` 单键硬上限 8KB，超过 7000 字节时只存本机，并清掉 `sync` 里的旧副本，避免两边数据不一致
4. **迁移**：老版本数据存在 `local`，升级后首次运行会自动搬到 `sync`（只搬一次）

**所以只要登录同一个账号并开启同步，换电脑后收藏会自动回来。** 面板底栏会实时显示同步状态和云端占用字节数；同步不可用时会明确提示「数据存本机」，不会假装同步成功。

另外，工具栏的显示 / 隐藏状态**故意留在本机**（`storage.local`），不跟着账号同步——那是个设备级偏好。

## 技术实现

- **Manifest V3**，`background.js` 用 service worker，无任何第三方依赖，总共约 900 行
- **界面全部在 `content.js` 的一张 Shadow DOM 里**，样式写在模板字符串里，与页面完全隔离
- **`storage.onChanged` 驱动刷新**：右键添加、其他标签页修改、别的设备同步过来，都会实时反映到已打开的页面上
- **图标兜底**：`<img>` 用 `referrer-policy: no-referrer`（不少 CDN 会因为 referer 拒绝返回）；加载失败、请求被墙、或者 5 秒还没回来，都会换成内置的地球线框 SVG
- **`crypto.randomUUID` 有降级**：`http://` 页面不是安全上下文，拿不到该 API，所以备了一条时间戳 + 随机串的降级路径
- **切标签页时自动收起**，避免切回来时残留展开状态

## 常见问题

**在 Edge 里加载后，之前收藏的都没了？**

扩展 ID 变了。本仓库的 `manifest.json` 保留了 `key` 字段，按上面「开发者模式加载」的步骤操作，ID 与商店版一致，数据不会丢。

**能用在 Chrome 上吗？**

代码只用了 `chrome.*` 标准 API，理论上可用。但 `manifest.json` 里的 `update_url` 指向 Edge 商店，在 Chrome 里可以删掉这一行再用开发者模式加载。

**数据存在云端安全吗？**

`chrome.storage.sync` 存的是你自己的浏览器账号同步空间，只有你自己的浏览器能读到，扩展本身不联网、不上传任何数据。
